# 课题组蒸馏工作流 + 轨迹分析

> 目标：给一个课题组（负责人 + 核心成员名单）建实证画像——成员产出、组结构、AI 化深度、两组对照。
> 前置：单人蒸馏工作流（workflow-single-scholar.md）已读。

---

## 输入

用户给的形式通常是：
- 负责人 + 研究方向 + 成员表（姓名/职称/方向）
- 或只给负责人名（先抓学校主页拿成员名单）

## Step 1 · 名单结构化

每个成员建一条记录：

```python
{"key": "yuan_sanyi", "zh": "袁三一", "group": "王尚旭课题组",
 "role": "教授·AI地震处理/储层预测/速度建模",
 "variants": [("Yuan", "Sanyi")],           # 英文名变体
 "anchors": ["Wang Shangxu", ...],          # 消歧锚点：已知圈内合作者
 "common_name": False}                       # 常见姓名？
```

**锚点种子来源**：负责人的已验证合作者圈 + 组内互为锚点 + 跨组成员双挂。
**注意跨组节点**：同时挂两组的成员（如黄捍东/陈双全/沈金松）是组间桥梁，单独标注。

## Step 2 · 批量爬取

跑 `scripts/crawl_group.py`（内置锚点消歧 + 假阳性过滤 + 重试）：
- 每人 CrossRef query.author + 主题词，rows=60
- 硬门禁：目标名在作者列表 + 常见名锚点共现
- 输出 `data/group_members_crossref.json`：每人 verified_hits / rejected / papers（含 anchor_cooccur）

**限速**：每人之间 sleep 1.5s，429 时退避重试（脚本内置）。

## Step 3 · 0 命中诊断（关键步，不许跳）

**0 命中 ≠ 没有产出**。对每个 0 命中成员：

1. **放宽到名字匹配**（去掉锚点门）重跑，看原始匹配数
2. **逐条看合作者圈**：
   - 圈内合作者出现 → 锚点表漏了，补锚点重跑
   - 圈外但方向吻合 → 候选论文，标"待人工甄别"（如周辉：Lingqian Wang 团队）
   - 完全同名不同人 → 标 same_name_trap（如 Yang Liu@中石油勘探院）
3. **结构性弱覆盖判定**：中文期刊为主的教授（尤其老教授），CrossRef 覆盖弱是正常的——反面探针走百度学术/CUPB 主页
4. 诊断结果写进 JSON 的 `diagnosis` 字段：verdict + candidate_papers + same_name_trap

**锚点门反向盲区**（李向阳案例）：国际合作圈学者（爱丁堡/BGP 出身）的锚点不在本校锚点表里，会被误杀。**锚点门只验证"属于这个圈"，不统计"全部产出"**——产出统计宁可漏（标待甄别）不可错（把别人的算进来）。

## Step 4 · 轨迹分析

对每组核心成员（验证命中 ≥10 者）做 AI/ML 关键词扫描（词表见单人工作流 Step 4）：

输出每人：AI/ML 论文占比 + 时间轨迹 + 范式分级（L0-L6）。

**组级判读**：
- **AI 执行核心是谁**——通常是验证命中最多 + AI 占比最高的学生代成员（袁三一 53 篇/41% 案例）
- **组的 AI 化起点**——最早那篇 AI 论文的年份和范式（不是最近那篇）
- **最新范式**——2025-2026 到了什么（自监督/生成式/扩散模型）
- **跨组桥梁**——双挂成员的 AI 论文算哪组的接口

## Step 5 · 两组对照（如果输入是两个组）

| 维度 | 对照项 |
|------|--------|
| 官方定位 | 组名本身（"油气人工智能研究课题组"=名字即战略） |
| AI 执行核心 | 谁、多少篇、什么范式 |
| AI 轨迹 | 起点年份 → 最新范式 |
| 英文产出强度 | CrossRef 验证命中总量 |
| 物理资产 | 装置/规则库/数据（决定断供风险） |
| 跨组节点 | 双挂成员 |

## Step 6 · 判据式结论 + 盯人名单

**结论模板**：
> {组A}与{组B}是{同构/异构}的转型模式：{核心判断}。盯人排序：{按 AI 化深度排}。0 命中成员需{补什么探针}。

**盯人排序逻辑**：AI 执行核心 > 物理引导 AI（L5）> 生成式落地（L6 应用）> 传统 AI 应用 > 0 命中待甄别。

## Step 7 · 落盘

```
工作区/scholar_crawl/课题组画像.md                 # 对比分析报告（交付物）
工作区/scholar_crawl/data/group_members_crossref.json
工作区/scholar_crawl/crawl_group.py               # 本组专用配置版（可留工作区）
```

回填：`assets/archived-scholars.md` 索引 + 工作区日志 + （有新坑时）tool-discipline.md。

## 实测性能参考（2026-09-27 CUPB 案例）

- 12 人 × CrossRef 60 条/人，总耗时约 3 分钟（含限速）
- 8 人验证命中（53/26/22/21/17/16/11/2 篇），4 人 0 命中（全部诊断出结构性原因）
- 假阳性拒掉率：34%-98%（常见名拒掉 60/60，生僻名拒掉 34/60）
- 诊断轮（0 命中者放宽重跑）额外 4 次查询，约 1 分钟
