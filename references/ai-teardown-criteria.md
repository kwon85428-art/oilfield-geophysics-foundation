# 能源 AI 拆解四问判据（物探环节）

> 用途：拆解任何"能源/物探 AI 产品/团队/论文"时的固定判据。缺一问 = 宣传大于工程。

---

## 四问本体

### Q1 · 求解器/内核是谁的？

- 自研十几年 vs 套壳开源 vs 第三方许可？
- **避谈出身 = 不敢查**。
- 物探语境细分：正演核（波动方程求解器）/ 反演核（优化算法）/ 岩石物理模型（Gassmann/接触理论）——问清楚是哪一层的"自研"

### Q2 · 校验规则库沉淀了多少？

- 需要"多少区块的坑"这种**可量化**答案
- 物探语境：井标定数据多少口井？多少个工区的处理流程沉淀？非重复性 4D 质控规则多少条？
- 答不出数字 = 还在学校原型阶段

### Q3 · 核心专业环节在链路里占什么位置？

物探→油藏链路：

```
[采集] → [处理] → [正演/标定] → [解释/AI反演] → [储层建模] → [井部署] → [动态监测(4D)]
   ↑         ↑          ↑              ↑                              ↑
   │         │     岩石物理标度化    AVO/流体识别物理约束          时移地震规则库
   │      去噪/成像/速度建模         （王尚旭学派位置）           （陈小宏学派位置）
   │
  物理模拟实验（含流体/裂缝）——正演数据的实验来源
```

- **刻意不提某个环节 = 该环节尚未自动化**（如油藏的历史拟合）
- AI 产品的宣传页把"解释/AI反演"画得很大、把"正演/标定"画没了 → 它没有物理内核，纯数据拟合

### Q4 · 断供风险是否为零？

**物探环节的断供分层**：

| 资产类型 | 断供风险 | 逻辑 |
|---------|---------|------|
| 物理规律（论文公开的） | **低** | 物理规律普适，文献开放渠道 |
| 实验装置（DARS 类） | 中 | 硬件原创设计，开源替代少；但数值模拟在侵蚀 |
| 规则库（4D 质控/区块经验） | **中-高** | 价值在唯一性，开源复刻即崩；且无工程代码 |
| 反演算法（贝叶斯/稀疏类） | 低 | 国际方法学，开源实现充足（Pyro/madagascar 等） |
| 商业软件栈（Landmark/Paradigm） | 高 | 完全垄断于国际厂商；论文能救命、代码救不了 |

**通用判据**：**物理内核提供者 vs 规则库持有者的断供风险方向相反**——
- 物理内核：资产公开 → 不怕断供，但**难护城**（开源数值模拟持续侵蚀）
- 规则库：资产私有 → 难替代，但一旦开源复刻就崩；**没 AI 化 + 没开源代码 = 卡在中间**

## AI 化轨迹判读（物探特化）

### 范式分级 L0-L6

L0 纯物理 → L1 优化算法 → L2 贝叶斯/稀疏 → L3 传统ML → L4 深度学习 → L5 物理引导AI（PINN/自监督） → L6 生成式（GAN/VAE/扩散）

### 判断一个团队/产品的真实 AI 水位

1. **看学生代/执行层的一作论文**，不看负责人挂名——"本人守物理侧、学生代执行 AI"是行业普遍模式（CUPB 两组同构验证）
2. **看轨迹连续性**：L1→L2→L5 连续爬升是真转型；直接跳 L4/L6 的是跟风
3. **看物理约束进没进损失函数/正演模型**："data-driven forward model"（袁三一 2021）、"geophysics-steered self-supervised"（唐跟阳 2023）是真 L5；只说 "deep learning" 不提物理的是 L4 外挂
4. **2026 年前沿水位**：扩散模型后验采样反演（李景叶线）、物理引导自监督（唐跟阳线）——产品还停在 CNN 年代的直接判过时

### 物探 AI 的固有认识论边界（引用自 oilfield-geophysics-assistant，判读时直接调用）

- 地球物理是**间接观测 + 数学反演**，反演天生多解——AI 只是新的反演算子，不是"看到了地下"
- 何治亮 2023 定调：「实现了单纯依据地震数据无法达到的预测目标」——凡声称纯地震/AI 即可定量缝洞物性含油性，用这句堵回
- 行业共识向物理信息收敛（PINN/可微分），纯数据驱动派在退潮

## 快速判读卡（产品/论文/团队通吃）

| 宣传话术 | 判读 |
|---------|------|
| "AI 地震解释，精度 95%+" | 问 hold-out 井？问训练集和测试集是不是同一工区 |
| "替代物探工程师" | Q3 链路图里它只占"解释"一段，前面的采集/处理/标定呢 |
| "自研 AI 内核" | Q1：正演核还是反演核？套的什么开源？ |
| "GPU 加速 XX 倍" | 要 CPU 基线加速比数字，说不清 = 营销（HiSimPro 判据同款） |
| "大模型物探助手" | 问 Q2：井标定规则库多少条？答不出 = RAG 套壳 |
| "物理驱动 AI" | 查损失函数/正演模型里物理进没进去，只挂名 = L4 冒充 L5 |

## 已建档案例（可直接引用的判读结论）

### 王尚旭课题组（CUPB，官方名"油气人工智能研究课题组"）
- **判读**：名字即战略。AI 执行核心袁三一（53 篇/41% AI/最高 164 被引），轨迹 L1(2009)→L2(2013)→L5(2021 数据驱动正演)→L5(2023 物理引导自监督)，连续 16 年
- **断供**：DARS 装置是护城河（中），物理规律公开（低），反演算法开源充足（低）
- **盯**：袁三一 > 唐跟阳（L5 自监督）> 陈双全（L6 VAE-GAN）> 王坤喜（L4→L5）

### 陈小宏课题组（CUPB）
- **判读**：组名无 AI 但李景叶线 2026 已到 L6 扩散模型——比王组更激进。本人数学物理派守门（贝叶斯骨架），学生代执行
- **断供**：4D 时移规则库 = 中国唯一系统化（难替代），但无开源工程代码（断供时代码救不了）
- **盯**：李景叶 > 黄光坦（叠前波形反演）> 王璞（L3→L4）

### 两组同构结论
> 两位 PI 都是"物理核 × AI 外壳"转型：本人守物理侧，学生代执行 AI 化。物理资产不同（DARS 装置 vs 4D 规则库），断供风险相反（难护城 vs 难替代）。**判断任何 CUPB 系物探 AI 产品，先问它站在哪个组的资产上。**
