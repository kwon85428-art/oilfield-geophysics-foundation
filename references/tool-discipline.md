# 工具纪律库：四类"沉默被当成结论"的坑

> 全部来自实测踩坑（2026-09-25 ~ 2026-09-27），每条含：症状 / 根因 / 判别 / 正解。
> 第一纪律：**任何"无记录/0 命中/未找到"结论前，必须做反面探针**。

---

## 坑型总览

四类坑同源——**模糊匹配 + 无校验 = 静默污染**，区别只在污染方向：

| 坑型 | 方向 | 典型案例 |
|------|------|---------|
| ① 静默错配 | 匹配到**不该匹配的** | scholar_crawl.py "Shuhong Wu" 错配到 Xinliang Tian |
| ② 无记录假阴性 | 没匹配到当成**没有** | 王大兴"OpenAlex 无记录"（实为 API 429） |
| ③ 元数据错标 | 匹配到本人但**字段错** | 陈小宏 ScholarID 被标 Sinopec |
| ④ 锚点门反向盲区 | **真论文被锚点误杀** | 李向阳国际圈论文被 CUPB 锚点门拒掉 |

**CrossRef 假阳性是坑①的主流变体**（2026-09-27 陈小宏案例）：`query.author` 模糊匹配捞进同姓学者，拒掉率可达 50%+。

## 坑① 静默错配 / 假阳性

### 症状
- 检索返回的论文**方向不对**（查油藏的返回海上风电）
- 被引数高得离谱（把同名大佬的算进来了）
- **脚本不报错**，返回 50 篇"正常"结果

### 判别
1. **逐篇核对作者全名列表**——目标名（含变体/缩写/连字符折叠）必须真正出现
2. 常见名（Liu Yang / Zhou Hui / Wu Di / Chen Xiaohong）加**锚点共现**：已知合作者圈至少一人在该篇
3. **合作者共现矩阵做第三方交叉**：查到的 50 篇里，与负责人/核心成员共现的比例是多少？低于 30% 可疑

### 已知陷阱名单（实测）
- `Chen Xiaohong` → Chen Yuqing/Schuster (KAUST)、Chen Fubin/宗兆云/印兴耀 (CUP华东)、Chen Wenchao/高静怀 (西安交大)、Chen Huaizhen/Innanen
- `Di Wu` → Ru-Shan Wu (UCSC, 439 被引)、Zedong Wu (KAUST)、Guochen Wu
- `Yang Liu` → 中石油勘探院 Jinshui Liu 团队的 Yang Liu
- `Hui Zhou` → 多个同名；CUPB 周辉的合作圈是 Lingqian Wang

### 正解
```python
# 双门禁（crawl_group.py 已内置）
if not any(name_matches(a, variants) for a in authors): reject  # 硬条件一
if common_name and not anchor_cooccur(authors, anchors): reject  # 硬条件二
```
OpenAlex 正解通道：`/institutions?search=` 定 id → `/works?filter=institutions.id:X,raw_author_name.search:变体` → Python 正则二次过滤 → 合作者共现交叉确认。

## 坑② 无记录假阴性

### 症状
- "OpenAlex 无记录" / "Scholar 覆盖弱" / "0 命中"
- API 实际返回 429/配额耗尽，但上层把它当成"查询成功、结果为空"

### 判别：反面探针（强制）
**换另一个索引再试一次**：
- 另一索引有实体 → **口径问题**，不是"没有"
- 全部索引都无实体 → 才是真的没有

探针池：CrossRef / OpenAlex / Semantic Scholar / 百度学术 / Scopus / IEEE Xplore / SciSpace / Bohrium / 学校主页。

### 结构性弱覆盖（不是坑，是常态）
**中国学者（尤其老一辈/工程界）大量成果在纯中文期刊**——英文索引覆盖窄是结构性的：
- 王大兴：76.9% 成果在纯中文期刊，Scopus 有实体但覆盖窄
- CUPB 刘洋/周辉/饶莹/吴迪：CrossRef 0 命中，但名字匹配 43-55 条——中文产出为主体
- **判据**：0 命中时先做名字匹配诊断（去掉锚点门），匹配条数多但锚点不共现 → 结构性弱覆盖 + 待甄别，**不是"没有"**

### 正解
1. API 报错码和空结果**分开处理**——429 ≠ 无记录
2. 中文一手资料兜底：学校主页 / 学院页 / 百科 / 邀请报告页（这些常有论文总数口径）
3. 档案里显式写"哪个索引查了/查到什么/哪个没查"

## 坑③ 元数据错标

### 症状
- ScholarID 页面 affiliation 与实际单位不符
- 百度学术把陈小宏标成"中国石油化工股份有限公司"

### 判别
**affiliation 字段不是"这个人是谁"的证据，是"这个索引抓到的机构标签"**。
验证归属看**合作者共现矩阵**：陈小宏条目的合作者（李景叶/Fomel/王本峰）明确指向 CUPB → 同一人条目、affiliation 抓取错。

### 正解
三线一致才确认同一人：论文标题方向 + 合作者名单 + 研究领域。affiliation 只作参考。

## 坑④ 锚点门反向盲区

### 症状
- 锚点消歧后，某成员 0 命中
- 但这人是**国际圈学者**（海外出身/国际合作主导），锚点表只放了本校圈

### 案例
李向阳（爱丁堡/BGP 出身，各向异性国际权威）：CrossRef 60 条里被 CUPB 锚点门拒掉 58 条——他真实的国际合作者（Crampin/Chapman/Edinburgh 圈）不在锚点表里。

### 判别
0 命中诊断轮（workflow-group.md Step 3）：放宽锚点门重跑，看被拒条目的合作者圈——
- 圈内人出现 → 补锚点
- 圈外但方向吻合 → 候选论文待甄别
- 学者本人的国际背景（海外 PhD/访问/外企）→ 锚点表先天不足，标注盲区

### 正解
**锚点门只验证"这人属于这个圈"，不统计"这人的全部产出"**。
- 归属验证：锚点门收紧（宁严勿松）
- 产出统计：换 OpenAlex institution filter + raw_author_name 通道，或人工补主页数据
- **宁可漏（标待甄别）不可错（把别人的算进来）**

---

## 通用判据（一页背诵版）

1. 检索返回的每篇论文，**核对作者全名列表**（坑①）
2. "无记录/0 命中"前，**换索引反面探针**（坑②）
3. API 报错 ≠ 空结果，**分开处理**（坑②）
4. affiliation 字段**不作身份证据**，看合作者共现（坑③）
5. 锚点门**只判归属不判产出**（坑④）
6. 中文期刊为主的学者，英文索引弱覆盖是**结构性常态**（坑②的物探版）
7. 一切统计数字的**真值来源必须比它更上游**（原始 API 响应 > 生成器输出 > 聚合报告）
